# WIIGA
Prototype of an intelligent water and energy optimization system using reinforcement learning

WIIGA- Water Intelligent Grid Application(Prototype)
     -Overview
WIIGA is a prototype exploring how reinforcement learning can optimize water distribution systems under energy constraints.
this project combines: Water network simulation
 Multi-source energy management (solar, grid, diesel)
 AI decision-making (PPO)
     -Prototype Scope
This is an early-stage proof of concept, including:
Custom Gymnasium environment, simplified hydraulic behavior(WNTR), Energy-aware pump control, PPO-based agent
     -Key Idea:
The agent learns to:
  Minimize energy costs
  Use solar energy when available 
  Maintain safe tank levels
While adapting to:
  Demand variation
  Energy price fluctuations
       -Note:
This prototype represents the first building block of the WIIGA system. It is designed to demonstrate the concept, not a finalized solution
